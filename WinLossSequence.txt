@startuml
title Win/Loss condition
actor User as Foo
participant Player as Foo1
participant GameScreen as Foo2
participant GooseContainer as Foo3
participant Timer as Foo4

== Win Condition ==

Foo --> Foo1 : 1) User moves the player to the bus
Foo1 --> Foo2 : 2) hasWon()
Foo2 --> Foo3 : 3) getGeese()
Foo3 --> Foo2 : 4) Geese: A list of geese not dispersed

Foo2 -> Foo4 : 5) getTime()
Foo4 --> Foo2 : 6) Time remaining

alt len(Geese) == 0 AND Time > 0
    Foo2 --> Foo1 : 7) True
    Foo1 --> Foo2 : 8) getScore()
    Foo2 --> Foo1 : 9) Score
    Foo1 --> Foo : 10) Player displayed getting on bus (win scene)
    Foo1 --> Foo : 11) Score is Displayed

else len(Geese) > 0 AND Time > 0
    Foo2 --> Foo1 : 7) False
    Foo1 --> Foo : 8) Tell user they can't board the bus (game continues)
end


== Lose Condition ==
loop Each frame while game is active (while time != 0)
    Foo2 --> Foo4 : 12) getTime()
    Foo4 --> Foo2 : 13) Time remaining

alt Time <= 0
        Foo2 --> Foo1 : 14) Player has lost
        Foo1 -> Foo2 : 15) getScore()
        Foo2 --> Foo1 : 16) Score
        Foo1 --> Foo : 17) Display player lost scene
        Foo1 --> Foo : 18) Display player's score
    end

end 


@enduml
